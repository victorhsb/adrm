# DM-0003: SPEC

## Status

accepted

## Definition

A functional requirements record: context, requirements, constraints, and acceptance criteria for a capability. SPECs capture the how of the system.

## Avoid

See [When to Use SPEC](0011-when-to-use-spec.md) for occasions where a SPEC is not the right record.

## Relationships

A SPEC's requirements depend on decisions recorded in [ADR](0001-adr.md)s. The meaning of SPEC itself is defined here, in the [Domain Model](0002-domain-model.md).
