# DM-0006: Kind

## Status

accepted

## Definition

The document type: adr, spec, or domain. Kinds share a parseable shape but live in separate directories with independent numbering. Repository configuration declares which kinds are required for readiness; a kind that is not required remains fully supported and its directory still joins the corpus when present.

## Avoid

- **category** — a category groups items within one store, kinds are separate stores
- **type flag** — kind is part of document identity (id prefix and directory), not a label

## Relationships

Every [ADR](0001-adr.md), [SPEC](0003-spec.md), and [Domain Entry](0005-domain-entry.md) has exactly one kind, encoded in its id prefix and directory. The [Corpus](0007-corpus.md) spans all three kinds.
